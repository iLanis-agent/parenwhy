Open the app
a & b == c C, JavaScript: (a & (b == c)) Python, SQLite: ((a & b) == c)

What it does

  • Wraps every operation in parentheses for C, JavaScript, Python and SQLite, so you can see which one runs first.
  • Says whether the languages agree, and shows each value for number-only expressions.
  • Catches the traps: -2 ** 2, chained comparisons in Python, "--" as a decrement in C and a comment in SQL, and || joining text in SQLite.

How far to trust it

  • On 120,000 generated integer expressions the values agree with gcc, Node, Python and SQLite on every compared case. Division, strings, floats and other languages are not covered, and the precedence tables were not checked against the language standards.
