ParenWhy

Type one expression. See how C, JavaScript, Python and SQLite each group it with parentheses, and the value each one gives.

Grouping rules are written from the languages' operator tables. They were checked by running 120,000 generated integer expressions through the real tools (gcc for C, Node for JavaScript, Python 3.10, SQLite 3.37.2) and comparing values with this engine: 0 differences (expressions with C undefined behaviour, results beyond JavaScript's exact integers, or no integer result were skipped, and counts are in the README). Not value-tested: SQLite's || (it joins text, so its value with comparisons may differ), division and modulo (parsed, not evaluated). Not covered: assignment, ternary, strings, floats, and Perl, Ruby and other languages. The precedence tables themselves were not checked against the language standards. Everything runs in your browser.
